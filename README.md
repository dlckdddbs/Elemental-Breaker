# Elemental Breaker (엘리멘탈 브레이커)

2023137015 이창윤 · 중간 프로젝트 (개인 과제)

불·물·풀 속성 상성을 노려 내려오는 벽돌을 깨는 세로형 모바일 벽돌깨기 게임

## 플레이

- 공개 URL: https://dlckdddbs.github.io/Elemental-Breaker/
- 스마트폰 세로 화면용 (480 × 854 비율)

## 실행 환경

- Unity 6.3 LTS (6000.3.11f1), Web 플랫폼, URP 2D
- GitHub Pages (`docs` 폴더) 배포, 모바일 브라우저 세로 화면

## 조작

| 조작법 | 방법 | 쓰임 |
|---|---|---|
| 스와이프 (드래그) | 화면을 누른 채 쏘고 싶은 곳으로 끌고, 손을 떼면 발사 | 공 조준·발사 |
| 클릭 버튼 | 하단의 아이템 · 공 속성 · 상점 버튼 | 폭탄·얼음 사용, 이번 턴 공 속성 변경, 아이템 구매 |
| 홀드 | 공이 날아가는 동안 빈 곳을 길게 누름 | 2배속 |

상단 오른쪽 톱니 버튼을 누르면 일시 정지 (계속하기 / 메인으로)

## 게임 방법

- 공을 쏘아 벽돌의 숫자(체력)를 0으로 만들면 벽돌이 깨집니다. 새로 나오는 벽돌의 체력은 턴 수와 같습니다.
- 속성 상성은 불 → 풀 → 물 → 불입니다. 이기는 속성으로 치면 피해와 골드가 2배이고, 지는 속성의 벽돌에 두 번 맞은 공은 그 턴에서 빠집니다.
- 줄마다 나오는 공 아이템을 먹으면 공이 1개 늘고, 다음 턴 공 속성이 그 아이템의 속성으로 바뀝니다.
- 벽돌을 깨서 모은 골드로 상점에서 속성 폭탄, 얼음(벽돌 하강 한 번 막기), 벽돌 속성 변경을 살 수 있습니다.
- 3·6·9턴에 상점 아이템이 하나씩 열리고, 10턴마다 골드 보상을 받습니다.
- 4턴마다 디버프가 걸립니다. 새 줄 체력 2배가 기본이고, 8턴마다 공 절반 · 아이템 금지 · 두 칸 하강 중 하나가 걸립니다.
- 벽돌이 맨 아래 줄에 닿으면 게임 오버입니다.

## 화면 흐름

로비 (이어하기 · 새 게임) → 게임 → 게임 오버 (도달한 턴 · 공 · 골드) → 다시 하기

진행 상황은 행동할 때마다 자동으로 저장되어, 다시 접속하면 로비의 이어하기로 계속할 수 있습니다.
